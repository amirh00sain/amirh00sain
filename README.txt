SpiderPanel landing page bundle

Files:
- landing.html: landing page
- globe.js: WebGL point-cloud globe (uses GPU when WebGL is available; lightweight Canvas fallback otherwise)
- galaxy.svg: animated galaxy background asset

Keep all three files in the same directory. Open landing.html in a modern browser. Google Fonts, live GitHub stars, and optional Natural Earth coastline refinement require an internet connection; the page has local fallbacks for fonts, globe geometry, and coastline data.
